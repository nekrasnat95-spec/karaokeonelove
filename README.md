# Что споём?

Страница для караоке: выбираешь настроение, язык и стиль, получаешь 10 песен. Нажатие на песню открывает поиск её текста на Genius.

## Как это устроено

- `index.html` — сама страница. Ключа Last.fm в ней нет.
- `scripts/fetch-songs.mjs` — собирает списки песен из Last.fm и сохраняет в `data/ru.json` и `data/en.json`.
- `.github/workflows/update-songs.yml` — запускает сборку каждый понедельник и по кнопке. Ключ берётся из секрета репозитория.

## Первый запуск (делает человек)

### 1. Получить ключ Last.fm

1. Зарегистрироваться на https://www.last.fm/join и подтвердить почту.
2. Открыть https://www.last.fm/api/account/create и заполнить:
   - Contact email — своя почта;
   - Application name — `Что споём`;
   - Application description — `Подбор песен для караоке`;
   - Callback URL и Application homepage — оставить пустыми.
3. Нажать Submit и скопировать **API key** (Shared secret не нужен).

### 2. Положить ключ в секреты GitHub

1. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
2. Name: `LASTFM_API_KEY`, Secret: вставить ключ, нажать **Add secret**.

### 3. Собрать списки песен

1. Вкладка **Actions** → слева «Обновить списки песен» → **Run workflow**.
2. Подождать 20–40 минут, пока появится зелёная галочка. В папке `data/` появятся `ru.json` и `en.json`.

### 4. Опубликовать страницу

1. **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`, **Save**.
3. Через пару минут вверху появится ссылка вида `https://<логин>.github.io/<репозиторий>/` — её можно отправлять друзьям.

## Важно

- Ссылка публичная: её откроет любой, у кого есть адрес. На странице только открытые данные о песнях.
- Язык Last.fm определяет по меткам, поэтому в списках иногда будут лишние песни.
- Какие метки Last.fm соответствуют настроениям и стилям, задано в начале `scripts/fetch-songs.mjs` (`STYLE_TAGS` и `MOOD_WORDS`) — их можно поправить и перезапустить сборку.
